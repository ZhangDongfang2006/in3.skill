## IN3 物料重复检查 - 规则反馈（Dongfang）

### Dongfang 强调的重复判断规则
1. **制造商完全不同 = 非重复** — 除非是命名不规范（如"宁波三爱"vs"三爱"、"海越电气"vs"海越湖北"）
2. **材质不同 = 非重复**
3. **方向或尺寸不同 = 非重复**
4. **型号中特定数字不同 = 非重复**（数字代表规格参数）
5. **颜色不同 = 非重复**
6. **不能光比百分比** — 要理解型号含义，很多型号中一位数字代表尺寸/颜色/大小，不同就是不同元器件
7. 回忆昨天规则 + 搜索行业标准补充

### 第二轮反馈（19:57）
1. **成品柜、外购成套不算重复** — 直接排除不参与对比
2. **Excel同一属性放同一列** — A和B的物料编号都放「物料编号」列
3. **EPS的3KW和37KW数字不一样不是重复** — 功率参数不同=不同产品
