## AI 物料查重（重大进展！）

### 背景

### 方法
1. 先用 Python 提取同名物料候选配对（677条）
2. 再用 AI（子代理）逐批判断每对是否重复
3. 共29批（每批500条），用5个并行子代理处理

### 结果对比
- **Python 规则脚本**：1条确认重复，0条待确认
- **AI 查重（初版）**：330条确认重复，45条待确认

### 逐步优化过程
1. v1：纯 AI 判断，规则太简单 → 结果太多
2. v2：加 sim≥0.95 阈值 → 待确认2,426条
3. v3：加制造商排除 + 全字段格式 → 85条确认重复

5. **名称语义优先**：先看是不是同一种东西，不是就不算重复
6. **富锌底漆 vs 环氧富锌底漆** → 成分不同 → 非重复
7. **塑粉 vs 油漆** → 不同工艺 → 非重复
