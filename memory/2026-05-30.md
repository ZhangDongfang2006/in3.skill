### v8 关键修复：表面处理差异在名称字段
- 不锈钢外六角螺丝 vs 镀彩外六角螺丝：描述都是 `M10×55,4.8级`，差异在名称

- 修复后多排除了12对，确认重复从135降到87

### Dongfang 今日新增规则
1. 镀彩 vs 不锈钢 → 不同表面处理/材质 → 非重复
2. 平垫加大 vs 普通 → 不同规格 → 非重复
3. 螺丝 vs 螺杆 → 不同产品 → 非重复
4. 驱动器 vs 顶升定位 → 不同产品 → 非重复
5. 名称语义优先：先看是不是同一种东西
6. 富锌底漆 vs 环氧富锌底漆 → 成分不同 → 非重复
7. 塑粉 vs 油漆 → 不同工艺 → 非重复
8. 底漆 vs 面漆 → 不同 → 非重复
9. **表面处理差异可能写在名称里而非描述里**（v8修复的核心）
