## 经验教训
1. IN3下载中心链接有时效性（约10分钟），签名过期后无法下载，需要重新导出
2. 采购订单明细的「下单时间」列名不是「下单日期」，脚本需要兼容两种命名
3. IN3浏览器操作：先切工厂再导航，避免页面跳转
4. 批量导出按钮是下拉菜单，需先点击展开再选"导出全部字段"
