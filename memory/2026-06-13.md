### 执行过程与问题记录

#### 问题1：IN3 菜单导航困难
- **现象**：点击左侧菜单「采购管理」展开后，点击「采购订单管理(ME20)」子菜单没有反应
- **原因**：IN3 左侧菜单结构是 `.vertical-menu-items`（复数，容器）包裹 `.vertical-menu-item`（单数，可点击项），之前一直在点击容器而不是可点击项
- **解决**：用 `document.querySelectorAll('.vertical-menu-item')` 找到实际可点击的菜单项
- **尝试过但失败的方法**：搜索框输入 ME20（会修改 placeholder 而不是 value，且无法触发 Vue 响应）

#### 问题2：搜索框输入方式错误
- **现象**：尝试用搜索框输入 ME20 跳转，结果 placeholder 被改成 "ME20"
- **原因**：用 `input.value = 'ME20'` 直接设置不会触发 Vue 的响应式更新
- **解决**：不使用搜索框，直接点击菜单项导航更可靠

#### 问题3：导出数据不完整
- **现象**：默认只导出了「未完成」的采购订单
- **原因**：IN3 默认勾选「只显示open PO」，URL 参数 `onlyOpen:true`
- **解决**：展开筛选条件，取消「只显示open PO」，重新查询后再导出
- **重要性**：价格异常分析需要全量数据（含历史价格对比），只导出 open PO 会导致历史均价不准确

#### 问题4：批量导出有下拉菜单
- **现象**：点击「批量导出」按钮后需要选择导出方式
- **选项**：「导出全部字段」和「导出当前配置字段」
- **解决**：选「导出全部字段」获取最完整数据
- **注意**：下拉菜单是 `<ul class="el-dropdown-menu">` 结构

#### 问题5：切换工厂后页面跳回首页
- **现象**：从宁波切换到湖北工厂后，URL 变成 /home
- **解决**：重新执行菜单导航步骤（采购管理 → 采购订单管理）

#### 问题6：弹窗干扰
- 「账号绑定确定」弹窗 → 点确定关闭
- 「通知」抽屉 → 关闭后才能继续操作

#### 问题7：CDN 下载域名拼写
- 正确：`tos-cdn-01.industics.com`（没有 r）
- 错误：`tos-cdn-01.industrics.com`（加了 r 会 SSL 错误）
