### 1. 物料重复检查

**详细流程**: `IN3物料重复检查流程.md`（同目录）
**分析工具**: `IN3数据/in3_dup_check.py` — 稳定 CLI 工具（旧版 `analyze_v3.py` / `compare_results.py` 已废弃）

**工具用法**:
```bash
# 分析最新的物料主数据
python3 IN3数据/in3_dup_check.py analyze IN3数据/物料主数据导出结果-2026-05-21.xlsx

# 对比两次结果
python3 IN3数据/in3_dup_check.py compare IN3数据/可疑重复物料-旧.xlsx IN3数据/可疑重复物料-新.xlsx

# 自动模式：找最新文件，分析并对比
python3 IN3数据/in3_dup_check.py auto
```

**简要步骤**:
1. 登录 IN3 → 系统管理 → 主数据管理 → 搜索 → 物料列表 → 批量导出物料 → 确定
2. 前往下载中心，等任务状态变为「已成功」后下载（约1-3分钟，非全屏等3分钟）
3. **只点一次导出，只下载一次**，不要重复操作
4. 运行 `python3 IN3数据/in3_dup_check.py auto` 自动分析并对比
5. 或者分步运行 `analyze` + `compare`
6. 与原始数据核对准确性后交付

**关键列映射**: col2=编号, col6=名称, col7=描述, col9=类别, col11=子类别, col13=制造商, col14=来源, col22=单位, col16=提前期, col61=价格, col70=创建人, col72=创建日期, col73=修改人, col75=修改日期

**核心判断原则**（Dongfang 强调）:
- 不能光比相似度百分比，要理解型号含义
- 制造商完全不同 = 非重复（除非命名不规范如"宁波三爱"vs"三爱"）
- 材质不同 = 非重复
- 方向/尺寸不同 = 非重复
- 型号中特定数字不同 = 非重复
- 颜色不同 = 非重复

**排除规则（算非重复）**: 甲供件、制造商完全不同、制造商一有一无、安装方向不同、断路器分断能力等级不同、脱扣曲线不同、极数不同、颜色不同、漏电类型不同、带附件vs不带、互感器差异、电线类型不同、保护类型不同、螺纹方向、版本号、脱扣方式、脱扣单元、配件差异、型号系列不同、材质不同、尺寸数值不同、额定电气参数不同、型号编码位不同、成品柜/外购成套不算重复、EPS等设备功率数字不同

**Excel格式**: A/B交替行、蓝色(#E8F0FE)/橙色(#FFF3E0)背景、差异字段红色字体、物料描述列宽50、备注列宽40、备注含排除原因、冻结前两列+前两行、自动筛选、同一属性放同一列、额外信息列（创建人/日期等）如果全空则不显示

**Excel格式**: A/B交替行、蓝色(#E8F0FE)/橙色(#FFF3E0)背景、差异字段红色字体、物料描述列宽50、备注含排除原因

### 2. 物料管理

**路径**：主数据管理 → 物料档案管理

**新建物料**:
1. 新建物料 → 搜索参考物料 → 选择物料模板
2. 修改新增物料信息 → 创建

**批量操作**:
- 批量导入：下载模板 → 填写物料信息 → 上传导入
- 批量导出修改：导出物料 → 修改后重新导入
- 上传后需确认所有物料是否解析成功

**MRP 物料属性规范**:
| 属性 | 说明 | 适用场景 |
|------|------|----------|
| 物料来源=自制 | 企业内部生产 | 成品（非外购型） |
| 物料来源=采购 | 外部采购 | 外购成品及外部物料 |
| MRP=无计划 | 仓库常备 | 通用耗材、标准紧固件 |
| MRP=项目需求计划 | 按项目需求 | 成品、元器件、项目特定物料 |

**注意事项**:
- 项目元器件需体现制造商/品牌信息
- 统一单位为"支"（只/个/套/件/台等），除非一套和一支代表不同物料
- 相同制造商名称必须统一（如"正泰电器股份有限公司"与"正泰"需统一）

**与金蝶对接**: 物料创建/更新时自动同步（FormId: BD_MATERIAL）

### 3. BOM 录入

**路径**：产品设计 → 产品BOM管理

**制作 BOM 模板**:
1. 选择销售订单 → 编辑BOM → 添加物料（先添加分组，再添加子物料）
2. 生效 → 保存为BOM模板（输入名称及版本号）

**添加 BOM 模板**:
1. 选择销售订单 → 编辑BOM → 选择项目分组
2. 添加BOM模板 → 选择模板 → 确认

**批量导入/导出 BOM**:
- 导出：选择产品 → 导出
- 导入：选择分组导入或全部导入 → 上传文件 → 确认

**注意事项**:
- BOM 是 MRP 计算的核心依据，必须确保完整性和准确性
- 精准录入各项物料用量
- 排除无效、停用物料

**与金蝶对接**: 工单创建或 BOM 变更后自动同步（FormId: PRD_PPBOMChange）

### 4. 销售订单管理

#### 完整流程（合同 → 订单 → 发运）

**Step 1: 新建销售合同**
路径：合同管理 → 新建合同
1. 填写合同基本信息（*号必填）
2. 维护交付内容（逐行添加非标产品 或 模板导入）
3. 保存 → 合同详情 → **下发工厂**

注意：外购件若无物料分类需与技术确认；变压器归为 DQ 电气元件

**Step 2: 新建销售订单**
路径：订单管理 → 新建销售订单
1. 参考单据类型 = 销售合同
2. 选择参考单据号关联合同
3. 维护交付内容：
   - **导入方式**：导出模板 → 填写标黄字段 → 导入（覆盖模式）
   - **直接添加**：选择非标成品，填入必选字段
4. 保存 → **下发工厂**

**Step 3: 销售发运**
路径：销售发运单 → 新建发运单
1. 点击销售订单编号选择订单
2. 填写基本信息 → 选择发货明细及数量
3. 保存并提交

#### 特殊场景处理
| 场景 | 处理方式 |
|------|---------|
| 框架合同部分下发 | 框架合同录入一次，每次口头合同作为新销售订单，关联同一框架合同 |
| 合同不收费但需出库 | 正常录入合同和订单，金额为0，发货做"其他出库"，金蝶不开发票 |
| 仅发票无实际发运 | 只在金蝶操作，IN3不操作 |
| 修改成品柜数量 | 直接修改，有问题先删除再新增 |

#### 与金蝶对接
- 销售订单创建并评审通过后 → 自动同步金蝶（FormId: SAL_SaleOrder）
- 销售出库后 → 自动同步（FormId: SAL_OUTSTOCK）
- 销售退货后 → 自动同步（FormId: SAL_RETURNSTOCK）
- 同步延时 <500ms，可在同步中心查看状态

#### 关键人员
- 销售：董桂晶（销售订单、发运单、退运单）

### 5. 采购申请

**路径**：采购管理 → 采购申请列表 → 新建采购申请单

**流程**:
1. 计划管理 → 订单物料明细 → 选择销售订单 → **导出订单物料明细**
2. 确认通用仓物料库存（有库存无需再下采购申请）
3. 新建采购申请单 → 选择采购类型及部门 → 导入采购申请 → 生成

**注意事项**:
- 高低压用料需下**独立采购申请**并备注
- 采购订单建立后需及时知会采购
- 订单物料有变更时及时通知采购
- **每月检查**未完成的采购申请，已采购完的废弃处理

**采购订单与到货数量不一致处理**:
路径：主数据管理 → 物料档案管理 → 编辑 → 容差设置
1. 设置"是否允许无限制的过量交货"
2. 保存后新建采购订单可见容差范围
3. 到货数量在容差范围内 → 关闭到货单 → 采购订单点击全部到货

**与金蝶对接**:
- 采购订单审批通过后 → 自动同步金蝶（FormId: PUR_PurchaseOrder）
- 采购入库后 → 自动同步（FormId: STK_InStock）
- 采购退货后 → 自动同步（FormId: PUR_MRB）
- 采购类型映射：110原材料→CGDD01_SYS, 130服务→CGDD05_SYS, 120委外→CGDD01_SYS, 140其他→CGDD05_SYS

### 6. 工单管理

#### 新建工单
**路径**：计划管理 → 工单管理 → 新建工单
1. 新建工单 → 选择销售订单编号
2. 工单类型 = 生产工单
3. 选择区域、产线、工艺路线
4. 填写生产数量、计划上线/完成日期、自制收货库存地点
5. 保存并退出

注意：参考单据类型一般选"关联销售订单"；工单BOM自动生成，工单内没有的物料选择"添加子件"

#### 工单领料
**路径**：仓库管理 → 生产领料 → 工单领料
1. 选择工单 → 填写生产组织、生产用户、申请人、自制发货库存地点
2. 提交 → 领料 → 选择仓库、库存地点、出库数量 → 提交

#### 其他领料
**路径**：仓库管理 → 其他领料单 → 新建领料单
1. 选择领料方式（关联SO领料 / 无单据领料）
2. 填写申请人、生产组织 → 添加物料及数量 → 提交 → 领料

#### 生产入库
**路径**：仓库管理 → 生产入库
1. 填写参考单据号、仓库、仓库地点、生产部门、记账日期
2. 填写库区、库位、入库数量 → 提交

#### 退料
- 工单领料退料：仓库管理 → 生产领料 → 生产领料工单退料
- 其他领料退料：仓库管理 → 其他领料单 → 新建退料单

#### 与金蝶对接
- 工单创建后同步（FormId: PRD_MO），无开工日期→计划确认/2，有开工日期→开工/4
- 领料出库后同步（FormId: PRD_PickMtrl）
- 生产入库后同步（FormId: PRD_INSTOCK）
- 生产退库后同步（FormId: PRD_RetStock）
- 退料后同步（FormId: PRD_ReturnMtrl）

#### 关键人员
- 生产计划：甘桃修（工单管理、BOM）

### 7. 铜排出入库

#### 分类规则
- 宽度 ≥30mm → 铜排仓（自动上料）
- 宽度 <30mm → 力臂货架（手动管理）

#### 采购入库
**≥30mm 铜排（自动入库）**:
1. 分类整齐放置在上料小车上
2. iPad 打开"IN工业制造运营铜排仓"APP
3. 高机系统开机（Z轴 -10~10），选自动/远程，按启动
4. 新建采购入库 → 选采购订单 → 选铜排规格
5. 列队执行 → iPad 基地扫描 → 自动吸盘入库

**<30mm 铜排（手动入库）**:
1. 按规格放于力臂货架
2. iPad 新建采购入库 → 选采购订单 → 选规格 → 完成

#### 铜排出库
- 铜排冲剪机加工：工程参数选6m，调出到105上料库位，自动转移
- 手动冲剪机加工：iPad 新建无项目出库，调出到104手动上料库位
- 力臂货架 → 线边仓：iPad 做库位转移

#### 线边仓出库流程
1. IN3 创建铜排半成品物料编码（描述按项目名称填写）
2. 创建铜排半成品生产工单，手动关联项目
3. 工单内添加工单BOM（工单管理 → 详情 → 工单BOM → 添加子件）
4. 填写实际铜排需求 → 保存
5. 铜排生产完成 → **完工**（线边仓库存自动出库，关联项目）
6. 仓库操作**生产入库**
7. 根据SO **领料**出库到对应项目

#### 新增铜排型号
1. iPad 基础设置 → 新增库位 → 填入规格
2. IN3 系统同步新增相同库位

### 8. 智能数字厂牌

#### 铭牌打印模板配置
**路径**：配置中心 → 铭牌配置 → 铭牌打印模板
1. 新建铭牌模板

2. 确认 → 修改数量 → 下一步 → 全部选中 → 配置模板 → 保存
3. 下一步 → **导出表格** → 填写箱柜参数 → **导入表格**
4. **生成铭牌计划** → **导出铭牌计划**

#### 激光打标机操作
1. 打开标刻模板 → 选择变量参数 → 使能变量文本 → 增加

3. 二维码：条形码选择 → 修改字体 → 填充 → 导入 → 确定
4. 所有变量修改后 → 标刻/F2

### 9. 异常处理

#### 未开工/取消但已录入系统的处理

**场景**：销售订单部分产品实际未开工或取消，但IN3已完成工单全流程。

| 步骤 | 操作人 | 操作内容 |
|------|--------|----------|
| 1 | 销售（董桂晶） | 创建**销售退运单**，相关产品数量改为1，保存 |
| 2 | 销售（董桂晶） | 执行**退库**，退到电气成品仓，记账日期当天 |
| 3 | 仓库（翁纯洁） | 做**其他出库**（通用库存出库），关联销售订单，选电气成品仓，记账日期当天 |
| 4 | 生产（甘桃修） | 计划管理 → 工单管理 → 输入销售订单查询 |
| 5 | 生产（甘桃修） | 找到相关产品 → 详情 → **撤回完工** |
| 6 | 生产（甘桃修） | 修改生产进度为 **0** → 保存 |
| 7 | 生产（甘桃修） | 重复 4-6 步骤 |
| 8 | 技术（李工） | 重新录入 BOM → 正常开领料单 → 完工入库 |

#### IN3与金蝶对接概要
- **对接方式**: OpenAPI 异步实时同步
- **中间件**: IN3 的 EDSB 中间件
- **同步延时**: <500ms
- **数据方向**: IN3 → 金蝶（单向推送），以 IN3 为准
- **同步中心**: 可查看状态和异常，支持人工重新同步或忽略
- **作废单据**: 调用金蝶【反审核】+【删除】
- **调用方式**: 创建金蝶单据需依次调用 保存→提交→审核
- **小数位**: 总价/成本取2位，单价取4位
